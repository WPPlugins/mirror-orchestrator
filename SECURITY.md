# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **WPPlugins Mirror Orchestrator**
(for example, token leakage in workflow logs, command injection via SVN/plugin
metadata, or GitHub App permission issues):

- **Do not** open a public GitHub issue.
- Report it privately via GitHub's **Security → Advisories → Report a
  vulnerability** on `WPPlugins/mirror-orchestrator`.

We will acknowledge receipt promptly and coordinate a fix before public
disclosure.
